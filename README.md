### Инструкция по запуску проекта

#### 1. Запуск сервера (Бэкенд)
Перейдите в папку backend, установите зависимости и запустите сервер:
cd backend
npm install
npm start

##### 2. Запуск интерфейса (Фронтенд)
В новом окне терминала перейдите в папку frontend, установите зависимости и запустите сборщик:
cd frontend
npm install
npm start

Проект откроется по адресу: http://localhost:8080
